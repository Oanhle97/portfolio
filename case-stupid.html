"Stupid" experiences from the products I use in Finland

A running notebook of UX problems in the consumer apps I use in Finland.

Sole Author · 2025–present · Personal Project

Why this project exists

I moved to Finland and started using the apps that shape daily life, grocery, banking, student housing, and so on. This is where I write those moments down, look at the intent behind the experience, and ask what I'd change.

How I audit

Each audit asks three questions:

  • What was I trying to do?
  • Where did the product fight me?
  • What's the smallest change that would help?

The friction is usually visible to anyone using the app, not just designers. Every proposed fix is something that could plausibly ship.

S-mobiili application

What was I trying to do

I'm a newcomer to Finland, and S-mobiili was my first Finnish bank account. The app was only available in Finnish. I often forgot my PIN code when depositing. The first time it happened, I screenshotted the interface and translated it with another app. After that, I'd try to find the "check PIN code" page by tapping around, hoping I'd land on it from visual memory. Sometimes I tapped into other features by mistake, and all of those taps cost me money.

Where did the product fight me

There was no English language option at the time. A user who can't read Finnish has only one strategy left: tap every icon and menu until something looks right. The interfaces for "Check PIN code," "Order card's PIN code by mail," and "Card with a PIN code of your choice" all sit in the same group and look almost identical (see below). All three charge a fee, and I had to tap through every one of them to find the one I actually wanted.

Why it breaks
  • The app is designed for Finnish-speaking customers as the default, not as a setting that can be changed. That's a localisation decision, not a usability one, but it shapes every other interaction.
  • The screens themselves look almost identical: same layout, same colour palette, same structure, same button placement. For a Finnish-speaking user, the titles tell them which screen they're on. For someone who can't read Finnish, the titles are just decoration, and the only thing left to navigate by is a sense of visual familiarity.
What's the smallest change that would help
  • Add an English language option (these have since been added).
  • The "Check PIN code" page and the "Order card's PIN code by mail" / "Card with a PIN code of your choice" pages should not look almost identical. A different layout would help users distinguish the page they use often from the pages they rarely need, without being charged for a mistake.
